# Портфоліо Бізнес-Аналітика

## Процес: Каскадна тригерна розсилка (Viber -> SMS)

### Опис бізнес-процесу (User Story)
Як маркетолог банку, я хочу автоматично відправляти повідомлення клієнту спочатку через Viber, а у разі помилки — через SMS, щоб зменшити витрати банку на розсилки.

### Основні кроки сценарію:
1. Система отримує подію (наприклад, реєстрація або транзакція).
2. Перевіряється наявність Viber у клієнта через API.
3. Якщо Viber є — надсилається Viber-повідомлення (чекаємо статус 5 хвилин).
4. Якщо Viber відсутній або виникла помилка доставки — автоматично надсилається SMS.
5. Процес завершується після підтвердження доставки.

### Схема процесу (BPMN 2.0)
```mermaid
graph TD
    A((Подія: Реєстрація / Замовлення)) --> B[Перевірити наявність Viber по API]
    B --> C{Viber є?}
    
    C -- Так --> D[Надіслати Viber-повідомлення]
    C -- Ні --> E[Надіслати SMS по API]
    
    D --> F{Успішно доставлено?}
    F -- Так --> G(((Повідомлення доставлено)))
    F -- Ні / Помилка 5 хв --> E
    
    E --> G

## Процес 2: Заохочення до відкриття кредитної картки (Тригер за лояльністю)

### Опис бізнес-процесу (User Story)
Як продуктовий аналітик банку, я хочу автоматично відстежувати активних користувачів, які здійснили 10 онлайн-покупок за дебетовою карткою, та надсилати їм персоналізовану пропозицію відкрити кредитну картку з пільговим періодом, щоб збільшити конверсію у кредитні продукти.

### Основні кроки сценарію:
1. Подія: Клієнт здійснює онлайн-оплату.
2. Система підраховує кількість онлайн-транзакцій за поточний місяць.
3. Якщо лічильник дорівнює 10:
   - Перевіряється наявність відкритої кредитної картки.
   - Якщо кредитної картки немає — генерується персоналізований тригер.
4. Клієнту надсилається PUSH-повідомлення у застосунок з пропозицією відкрити картку в 2 кліки.
5. Якщо PUSH не прочитано протягом 24 годин — надсилається повторне нагадування у Viber/SMS.

### Схема процесу (BPMN 2.0)

```mermaid
graph TD
    A((Подія: Онлайн-оплата)) --> B[Збільшити лічильник покупок +1]
    B --> C{Кількість покупок = 10?}
    
    C -- Ні --> D(((Завершення сценарію)))
    C -- Так --> E{Є відкрита кредитка?}
    
    E -- Так --> D
    E -- Ні --> F[Сформувати PUSH-пропозицію]
    
    F --> G[Надіслати PUSH у застосунок]
    G --> H{Прочитано протягом 24г?}
    
    H -- Так --> D
    H -- Ні --> I[Надіслати нагадування Viber/SMS]
    I --> D
