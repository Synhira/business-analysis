# Портфоліо Бізнес-Аналітика

Вітаю! У цьому репозиторії представлені приклади моделювання банківських бізнес-процесів, тригерних розсилок та cross-sell логіки у форматі BPMN 2.0 (за допомогою Mermaid.js) та Markdown.

---

## 📋 Перелік бізнес-процесів

### 1. [Каскадна тригерна розсилка (Viber -> SMS)](./cascade-notification.md)
* **Напрямок:** Маркетингова автоматизація / Оптимізація витрат.
* **Суть:** Автоматична перевірка доступності каналів зв'язку (Viber API) та фолбек на SMS у разі недоставимості.

### 2. [Заохочення до відкриття кредитної картки (Тригер за лояльністю)](./loyalty-credit-card-offer.md)
* **Напрямок:** CRM & Cross-sell / Data-driven тригери.
* **Суть:** Відстеження транзакційної активності (10 онлайн-покупок за дебетовою карткою) та генерація персоналізованої PUSH/Viber пропозиції.

---

### 🛠️ Використані інструменти та методології:
* **Моделювання процесів:** BPMN 2.0 (Mermaid.js)
* **Документування вимог:** Markdown, User Stories
* **Системи та протоколи:** REST API, PUSH / Viber / SMS Gateway
