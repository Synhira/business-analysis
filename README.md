# Портфоліо Бізнес-Аналітика

## Процес 1: Каскадна тригерна розсилка (Viber -> SMS)

### Опис бізнес-процесу (User Story)
Як маркетолог банку, я хочу автоматично відправляти повідомлення клієнту спочатку через Viber, а у разі помилки — через SMS, щоб зменшити витрати банку на розсилки.

### Основні кроки сценарію:
1. Система отримує подію (наприклад, реєстрація або транзакція).
2. Перевіряється наявність Viber у клієнта через API.
3. Якщо Viber є — надсилається Viber-повідомлення (чекаємо статус 5 хвилин).
4. Якщо Viber відсутній або виникла помилка доставки — автоматично надсилається SMS.
5. Процес завершується після підтвердження доставки.

### Схема процесу (BPMN 2.0)

```mermaid
graph TD
    A((Подія: Реєстрація або Замовлення)) --> B[Перевірити наявність Viber по API]
    B --> C{Viber є?}
    
    C -- Так --> D[Надіслати Viber-повідомлення]
    C -- Ні --> E[Надіслати SMS по API]
    
    D --> F{Успішно доставлено?}
    F -- Так --> G(((Повідомлення доставлено)))
    F -- Ні або Помилка 5 хв --> E
    
    E --> G
    graph TD
    A((Подія: Онлайн-оплата)) --> B[Збільшити лічильник покупок на 1]
    B --> C{Кількість покупок дорівнює 10?}
    
    C -- Ні --> D(((Завершення сценарію)))
    C -- Так --> E{Є відкрита кредитка?}
    
    E -- Так --> D
    E -- Ні --> F[Сформувати PUSH-пропозицію]
    
    F --> G[Надіслати PUSH у застосунок]
    G --> H{Прочитано протягом 24г?}
    
    H -- Так --> D
    H -- Ні --> I[Надіслати нагадування Viber або SMS]
    I --> D
