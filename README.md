## 🗂️ Перелік бізнес-процесів та проєктів:

### 🏦 Напрямок: FinTech / CRM-маркетинг (Для банківського сектору)
* 💬 **[Кейс 1. Каскадна тригерна розсилка (Viber -> SMS)](./cascade-notification.md)** — проєктування логіки фолбеків по API через шлюз розсилок із таймаутом доставки для оптимізації витрат банку.
* 💳 **[Кейс 2. Заохочення до відкриття кредитної картки (Cross-sell)](./loyalty-credit-card-offer.md)** — аналіз транзакційної активності за дебетовою карткою для генерації персоналізованих PUSH-пропозицій.

### 🏥 Напрямок: Healthcare / Продуктовий аналіз (Для медичних систем)
* 💬 **[Кейс 3. Каскадні комунікації та автоматизація акцій (Кейс "Мамографія")](./healthcare-marketing-cascade.md)** — логіка сегментації бази пацієнтів, автоматизації сповіщень та аналіз ефективності каскаду проти ручного обдзвону.
* 🏥 **[Кейс 4. Модуль онлайн-запису користувачів та інтеграція з МІС](./healthcare-booking.md)** — синхронізація вільних слотів у графіку через API, усунення проблеми double-booking за допомогою обробки HTTP-статусів `201 Created` та `409 Conflict`.
